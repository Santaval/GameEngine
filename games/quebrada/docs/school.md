# School sheet (`tilesets/school.png`, `school.tsx`)

Fourth tileset of `maps/zona1.tmx` (after town, buildings and park), generated by `tools/tilegen/catalog_school.mjs` (`make tiles` / `node tools/tilegen/gen.mjs`).
`firstgid` = 721 = 144 (town) + 384 (buildings) + 192 (park) + 1, computed in `zona1_map.mjs` as `SCHOOL_FIRSTGID`, never typed. Sheet: 16 x 22 tiles of 16 px (352 slots, 221 used; rows 14-21 hold the Colegio). First-pass procedural art
(shapes and colours after `docs/reference/escuela/escuela-frente.jpg`). Every tile name starts with `escuela_`. Property scheme as `town.tsx`: `name`, `layer` (`ground|overlay|ysort|above`), `surface` only on non-solid ground,
`solid` only on `ysort`, `sort_offset`. `tests/school_check.lua` validates it.

| Tiles | Sheet position | Layer / props |
| --- | --- | --- |
| `escuela_aulas_a_<cx>_<cy>` (10x6 cells, cream walls) | rows 0-5, cols 0-9 | rows 0-3 roof: `above`, never solid (red corrugated zinc, hip roof, pink beam); row 4 wall (windows with wooden frame + grille, 2 green doors): `ysort` solid; row 5 corridor (pink columns, wooden benches, concrete floor): `ysort`, `sort_offset -16`, walkable |
| `escuela_aulas_b_<cx>_<cy>` (10x6, ochre walls) | rows 6-11, cols 0-9 | same |
| `escuela_aulas_{a,b}_lit_<cx>_<cy>` | rows 12-13 | glowing window glass for the `windows_lit` layer (`ysort`, `sort_offset 1`) |
| `escuela_patio_a`, `_b`, `_grieta` | row 0, cols 10-12 | `ground`, `surface concreto` |

| `escuela_pilar` | row 0, col 15 | `ysort` solid: whitewashed pillar (corners, gate posts) |
| `escuela_asta_0_0..0_2` (flagpole 1x3) | rows 2-4, col 10 | two upper cells `above` (flag), base `ysort` solid |
| `escuela_rotulo_<cx>_<cy>` (sign 2x2) | rows 2-3, cols 11-12 | board row `above`, posts row `ysort` solid |

Each building has its own `roof_<name>` layer (`above`, `roof_of`) and a `roofs` object, footprint collision rows 1-4, lit windows and window lights like the church. The placement, plot layout and coordinates are in [zona1.md](zona1.md#the-escuela-and-casa-de-olguita-east-of-the-asphalt-street).
`gen.mjs --preview DIR` writes `school_sheet_x4.png`, `crop_escuela_aulas_a_x4.png` and the `zona1_escuela*_x2.png` crops (day, night, no roof, interactables overlay).

## El Colegio (Liceo), across the street from the cafetal

Same sheet. `escuela_colegio` (10x6, rows 14-19, lit cells rows 20-21): light-green walls, blue zinc roof, white beam and columns, brown doors; `escuela_rotulo_colegio` (2x2, rows 2-3, cols 13-14) is the "COLEGIO" sign.
Placement (`COL_*` in `zona1_map.mjs`, all derived from the cafetal's columns): plot = the cafetal's 25 columns, rows `SIDEWALK_S_Y + 2` .. +21 on the SOUTH side of the main street; whitewashed wall + chain-link fence, 2-tile gate on the NORTH fence
at the cafetal's aisle columns (so the aisle and the gate path line up across the street). Aulas in the north-east of the plot facing a concrete patio; flagpole, sign, trees. Doors: "El colegio está cerrado." Zone `colegio`.
`make tiles --preview DIR` writes `zona1_colegio_x2.png` (day / noroof / night) and `crop_escuela_colegio_x4.png`.
