# Ebais sheet (`tilesets/ebais.png`, `ebais.tsx`)

Fifth tileset of `maps/zona1.tmx` (after town, buildings, park and school), generated by `tools/tilegen/catalog_ebais.mjs` (`make tiles` / `node tools/tilegen/gen.mjs`).
`firstgid` = 945 = 144 (town) + 384 (buildings) + 192 (park) + 224 (school) + 1, computed in `zona1_map.mjs` as `EBAIS_FIRSTGID` (previous firstgid + previous capacity), never typed.
Sheet: 16 x 16 tiles of 16 px = 256 slots, 113 used. First-pass procedural art (shapes and colours after `docs/reference/clinica/ebais-rampa.jpg`: stone-clad upper wall, blue corrugated zinc roof over the
main block and a lower roof over the covered concrete access ramp with yellow railings, light-blue walls, white square columns, wooden-slat eave, blue plastic benches). Every tile name starts with `ebais_`.
Property scheme as `town.tsx`: `name`, `layer` (`ground|overlay|ysort|above`), `surface` only on non-solid ground, `solid` only on `ysort`, `sort_offset`. `tests/ebais_check.lua` validates it.

## One building cell, two tiles

`ebais_edificio` (12 x 7 cells = 192 x 112 px, facing SOUTH) is drawn on two canvases of the same grid, so a cell can carry a **wall tile** and a **roof tile**:

| Tiles | Sheet position | Layer / props |
| --- | --- | --- |
| `ebais_edificio_techo_<cx>_<cy>` (roof) | rows 0-6, cols 0-11 (id = cy * 16 + cx) | `above`, never solid, in the map layer `roof_ebais_edificio` (`roof_of`). Rows 0-2: the main blue corrugated hip roof; rows 5-6 (cols 2-9): the lower porch roof with its wooden-slat eave |
| `ebais_edificio_<cx>_<cy>` (wall) | rows 7-13, cols 0-11 (id = (7 + cy) * 16 + cx) | `ysort`, in the map layer `buildings`. Rows 3-4 (24 cells): stone-clad band + light-blue wall, 4 windows with white grilles (two per wing), double glass door in the middle (cx 5-6), all `solid`. Rows 5-6, cols 2-9 (16 cells): the covered porch (concrete floor, ramp with yellow stripes and railings, 4 white columns), walkable: `sort_offset -16`, not solid |
| `ebais_edificio_lit_<cx>_<cy>` | rows 14-15 | glowing window / door glass for `windows_lit` (`ysort`, `sort_offset 1`) |
| `ebais_piso_a`, `_b`, `_grieta` | row 0, cols 12-14 (ids 12-14) | `ground`, `surface concreto` (patio, path, parking) |
| `ebais_parqueo_linea` | row 0, col 15 (id 15) | `ground`, `surface concreto`, a painted white stall line |
| `ebais_banca` | row 1, col 12 (id 28) | `ysort` solid: blue plastic bench |
| `ebais_maceta` | row 1, col 13 (id 29) | `ysort` solid: potted plant |
| `ebais_basurero` | row 1, col 14 (id 30) | `ysort` solid: blue drum bin on a post |
| `ebais_rotulo_0_0`, `ebais_rotulo_1_0` (sign 2x1) | row 2, cols 12-13 (ids 44-45) | `ysort` solid: small "EBAIS" board on two posts |

The map uses the school's `escuela_cerca_h/_v/escuela_pilar` for the plot fence (the school sheet is unchanged). Trees are the town's (`guanacaste`, `monte`, `platano`).
The building has a collision footprint rect (`ebais_edificio_footprint`, rows 1-4 of the building) in the `collision` group, a `roofs` object, `luz_ebais_edificio_1..4` window lights and `luz_ebais_puerta`, all `only=dusk,night`, from the generic building placement.
Placement, plot layout and coordinates: [zona1.md](zona1.md#the-ebais-health-clinic-south-west-corner-of-the-park-south-of-the-south-street).

## Moving or replacing it

- **Move the plot**: the `EB_*` constants in `zona1_map.mjs` (`EB_X1` derives from the lastre street column `WEST_X`, `EB_Y0` from the south street). The elements `ebais_*` all derive from them; the zone, the door interactable, the lights and the footprint follow.
- **Move only the building**: change `EB_AT` (door x, interactable, path rows and the checks in `gen.mjs` follow); keep the 2-wide path (`EB_GATE`) next to it.
- **Redraw the art**: edit `drawWall`, `drawRoof`, `drawWallLit` in `catalog_ebais.mjs` (keep the porch inside cells 2-9 of rows 5-6 and the 12 x 7 grid, otherwise the walkable cells and the tests change), then `node tools/tilegen/gen.mjs`.
- **Replace with another clinic**: add a building entry (same shape as `EBAIS_BUILDINGS`) or swap `name` in the `ebais_edificio` element; keep the `ebais_` prefix, the `roof_<name>` layer and the footprint.
- A north-facing variant (door in the top wall, toward the street) is a later improvement: the generic doors of this game's art all face south.
