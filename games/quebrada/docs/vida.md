# Vida sheet (`tilesets/vida.png`, `vida.tsx`)

Eighth tileset of `maps/zona1.tmx`, appended after `rio` so no earlier firstgid moves (`VIDA_FIRSTGID` in `zona1_map.mjs`, computed). Generated by `tools/tilegen/catalog_vida.mjs` (`make tiles`).
Sheet: 16 x 16 tiles of 16 px (256 ids). Every tile name starts with `vida_`. Property scheme as `town.tsx` (`name`, `layer`, `surface` only on walkable ground, `solid` only on `ysort`, `sort_offset`, optional animation).
`tests/vida_check.lua` validates it.

| Ids | Content |
| --- | --- |
| 0-63 | name plaques `vida_rotulo_<key>_<cx>_0` (ysort, solid), 1 row tall and 3-4 tiles wide, text with the shared 3x5 pixel font (`tools/tilegen/font.mjs`) |
| 64-255 | reserved for street life (animals, bus stop, laundry, moto, poles, signs) |

## Name plaques

`PLAQUES` in `catalog_vida.mjs`: `{ key, lines, style }`. Style `post` is a cream board on two wooden posts (one line); style `fence` is a board hung on a wire fence (up to two lines). The width is
`ceil((widest line in px + 4) / 16)` tiles (the font advances 4 px per character), at most 4, otherwise the generator throws. Plaques are placed with an `object` element (`name: "vida_rotulo_<key>"`).
Keys: `berta`, `maria_juvenal`, `isabel`, `carmen`, `machillos`, `ingracia`, `guarderia`, `caliles`, `enrique`, `paula`. Accents are dropped by the font (DONA, TIO), only the Ñ is kept.
