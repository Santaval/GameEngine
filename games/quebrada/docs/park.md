# Park sheet (zone 1, the park)

Third tileset, **generated by code** like the town and buildings sheets: `tilesets/park.png` + `tilesets/park.tsx`
(`tools/tilegen/catalog_park.mjs`; run `make tiles`). 256x192 px, 16 columns x 12 rows, **96 tiles**, ids 0-181.
Maps declare it after the other two: `firstgid = town tilecount (144) + buildings tilecount (384) + 1 = 529`
(`PARK_FIRSTGID` in `zona1_map.mjs`, computed, never typed). First-pass procedural art: readable shapes, to be redrawn.

Same property scheme as the town sheet: `name` (all prefixed `park_`), `layer` (ground | overlay | ysort | above),
`surface` (only non-solid ground tiles: skate, banks, court, lines, walkway = `concreto`; sand = `lastre`),
`solid` (only `ysort` tiles), `sort_offset`. Multi-cell objects are drawn on one canvas and sliced (as the trees in
`catalog_plants.mjs`): upper cells `above`, base cells `ysort` + solid.

Layout: row 0 skate floors | row 1 banks (edges `park_bank_<high side>`, pit corners `park_bank_in_*`, pyramid corners
`park_bank_out_*`) | row 2 sand, court floors, walkway | row 3 court line pieces `park_line_<arms>` (n, s, e, w) |
row 4 rails, box, bench, seesaw | rows 5-9 swing (3x2), slide (2x2), climbing frame (2x2), hoops (1x2), goals (1x5) |
rows 10-11 centre circle cells (7x8 block, only the cells the ring/line touches exist).
The line pieces keep a 2 px line on pixels 7-8, so the map builder joins them by neighbours (`court_lines` element).

Ramps/banks are walkable decoration (ground). Rails, boxes, benches, seesaw, equipment posts, hoop poles and goals are solid.
