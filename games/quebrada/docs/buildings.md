# Buildings (issue #71)

A second tileset, `tilesets/buildings.png` + `tilesets/buildings.tsx`, **generated by code** like the town sheet
(`tools/tilegen/catalog_buildings.mjs`, `building_draw.mjs`). It holds the church, mama's house, three filler
houses, the interior of mama's house, lit window cells and two coloured hedges. Regenerate with `make tiles`;
never edit the PNG / TSX / generated maps by hand.

| File | What |
| --- | --- |
| `tilesets/buildings.png` | 256x384 sheet, 16 columns x 24 rows. **Generated.** |
| `tilesets/buildings.tsx` | Tile properties (`name`, `layer`, `solid`, `sort_offset`). **Generated.** |
| `maps/buildings_demo.tmx` | 40x30 proof map: church, mama's house, three houses. **Generated.** Key `9` in the main scene. |
| `maps/house_mama.tmx` | Interior of mama's house. **Now generated** (`tools/tilegen/interior_map.mjs`): hand edits are overwritten. |
| `scripts/roofs_logic.lua`, `scripts/roofs.lua` | Roof fade and window glow (pure logic + engine glue) |

Both tilesets are declared in every map that uses them: town with `firstgid="1"` and buildings with
`firstgid="145"` (= town tile count 144 + 1; always compute it, never guess).

## Sheet layout

Landmarks are drawn whole on one canvas and sliced into 16x16 cells; a fully transparent slice produces no tile.
Cell names are `<building>_<cx>_<cy>` (cx, cy = cell inside the building).

## Tile property rules

- Roof cells (`layer=above`) are never `solid` and never have a `surface`. Because roof cells cannot block,
  **every building needs collision rects** in the map's `collision` object group covering the roof-covered part
  (the generator emits `<name>_footprint`). If you stamp a building by hand in Tiled, add them yourself.
- Base cells are `layer=ysort`, `solid=true`, except the cells listed as `open` (mama's porch), which are walkable
  and carry `sort_offset=-16` so that the hero draws in front of them.
- No building tile has `surface`; the ground under it gives the footstep sound. Mama's porch has a `surface`
  rect (`porche_mama`, madera) on top of `plank_h` ground tiles.
- Lit cells are `ysort` with `sort_offset=1` (just after the wall cells of the same row).
- Interior furniture is `ysort`, not solid (the collision rects of the map block the player); the back wall is solid.

## Map conventions

Tile layers, in order: `ground`, `overlay`, `objects` (ysort: trunks, hedges), `buildings` (ysort: every base cell),
`windows_lit` (ysort), one `roof_<name>` layer per building and `canopy` (above, last).

- Each `roof_<name>` layer has `above=true` and `roof_of=<name>`. `set_roof_alpha(<name>, a)` fades every layer
  with that `roof_of` (see `engine/docs/lua-api.md`).
- The `roofs` object group has one `class = "roof"` rect per building (the **whole** building area) with the
  property `roof_of` (and optionally `min_alpha`, default 0). While the hero's foot box overlaps the rect, the
  roof fades to `min_alpha` at 600 alpha/s; outside it fades back. Two rects with the same `roof_of`: the lowest wins.
- `scripts/town_controller.lua` runs `scripts/roofs.lua` when `tile_map` is on (config `roofs`, nil follows
  `tile_map`). `world_debug = false` hides the grid, collision and door rects that the controller normally paints
  over the map; `buildings_scene.lua` and `house_scene.lua` use it.
- Doors: `door_mama` is a 32x12 rect just below the door cell; `exit_mama` is 28 px under the rect's top, centred.

## Window glow at night

Two layers cooperate: `light` objects (`only = "dusk,night"`, handled by `time_of_day.lua`) light the ground, and
the `windows_lit` tile layer paints the panes themselves in warm colours. `scripts/roofs.lua` sets the layer alpha
from `tod.visible("dusk,night")` (255 / 0, ramped at 170 alpha/s). The church only lights its door lintels.

## Interior (`maps/house_mama.tmx`)

12x9 cells, same ids, names and properties as the hand-written file of #62. Tile layers: `floor` (town `plank_h`),
`walls` (ysort, back wall with a curtained window and saint pictures) and `furniture` (ysort), drawn at the pixel
positions of the old rects (table 24,24 48x32; chair under `mama` 48,60; radio on a stool 72,60; bed 144,24; shelf with
the flashlight and charger 88-136,24). New group `seats` with `seat_mama` (class `seat`, props `npc=mama`,
`facing=down`); no code reads it yet. `mama` got a provisional `figure` colour.

## Adding a building later

1. Add an entry to `BUILDINGS` in `catalog_buildings.mjs` (size, `roofRows`, `footRows`, `open`, `windows`, `door`,
   `draw`, `drawLit`) on free cells of the sheet; lit cells are packed from id 288 automatically.
2. Place it in `PLACE` of `buildings_map.mjs` (or a new map generator) and add its `roof_<name>` layer.
3. `make tiles`, then check `gen.mjs --preview <dir>` (`buildings_demo.png`, `_noroof`, `_night`).

## Limits

- 32 lit slots (ids 288-319; see the generator for how many are used), 48 interior furniture slots (33 used at the time of writing).
- The porch row is walkable only because its cells are transparent apart from a post.
- Hand-written Tiled edits to generated maps are lost on the next `make tiles`.
